
## Admin dashboard

Open `admin.html` to access the barangay staff portal. It includes:

- Request monitoring and search
- Status controls: Pending, In process, Completed
- Request totals dashboard
- Form for publishing project updates, announcements, and reports
- Delete controls for published updates

Demo admin login:

- Email: `admin@barangay.ph`
- Password: `admin123`

The admin page and resident page share demo data using browser `localStorage`. For a real deployment, add a secure backend/database and role-based authentication.
