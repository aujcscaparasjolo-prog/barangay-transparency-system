# BarangayConnect — Transparency & Documentation Request System

A responsive HTML/CSS/JavaScript prototype for a barangay transparency portal. It runs directly in Visual Studio / Visual Studio Code without a backend.

## Run locally

1. Clone or download this repository.
2. Open the folder in Visual Studio or Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Included features

- Login and sign-up interface
- Public overview of barangay services and updates
- Documentation request form
- Request status tracking with search and filters
- Barangay updates for projects, meetings, and reports
- Responsive mobile layout
- `localStorage` demo persistence for the logged-in user and requests
